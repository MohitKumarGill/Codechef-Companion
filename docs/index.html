🍳 CodeChef Companion

A Chrome / Brave extension that makes CodeChef practice smoother.

View on GitHub Install (from source)

Features

  • 📋 Copy the problem (statement, constraints, samples) to your IDE in one click.
  • 💾 Save problems & solutions locally, per language, with tags and status.
  • 📥 Paste code back into CodeChef's editor from your clipboard or saved library.
  • 🤖 Ask ChatGPT to solve the current problem (web UI or optional OpenAI API key).
  • 🖱️ Draggable toolbar · ⌨️ Ctrl+Shift+V paste · Ctrl+Shift+G ask ChatGPT.

Privacy

No backend, no accounts, no tracking. Everything stays in your browser's IndexedDB and chrome.storage.local. The only outbound call is to api.openai.com — and only if you supply your own API key.

Install (from source)

  1. git clone https://github.com/MohitKumarGill/Codechef-Companion.git
  2. Open chrome://extensions (or brave://extensions)
  3. Enable Developer mode
  4. Click Load unpacked → select the cloned folder

Then open any https://www.codechef.com/problems/<CODE> page. A floating panel appears bottom-right.

Compatible with Chrome 120+ and Brave 1.60+. Not for Firefox. Use for practice only — not in rated contests.
